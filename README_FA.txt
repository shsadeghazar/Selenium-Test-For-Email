نسخه حداقلی پشتیبانی CAS
=========================

این بسته بر پایه فایل‌های اصلی شما ساخته شده است.

مواردی که تغییر نکرده‌اند:
- بدنه و مراحل سناریوهای تمام فایل‌های test_*.py همان نسخه اصلی هستند.
- منطق تشخیص request و performance log تغییر نکرده است.
- فهرست 17 گزینه Runner، شمارش موفق/خطا و قالب HTML لاگ همان نسخه اصلی است.
- session_manager.py در این بسته وجود ندارد.

تنها تغییرهای انجام‌شده:
1) login_and_save.py
   - ورود مستقیم و CAS را تشخیص می‌دهد.
   - برای بازگشت CAS به دامنه اصلی حداکثر 60 ثانیه منتظر می‌ماند.
   - کوکی accounts را ذخیره نمی‌کند.
   - کوکی قابل استفاده روی دامنه سامانه و storage همان دامنه را ذخیره می‌کند.
   - ساختار قدیمی cookies/local_storage/session_storage را حفظ می‌کند.
   - مسیر واقعی برنامه را در app_base_url ذخیره می‌کند.

2) session_url.py و دو خط محدود در ابتدای هر تست
   - سشن قدیمی یا ورود مستقیم همچنان از /nui/ استفاده می‌کند.
   - سشن CAS از مسیر واقعی ذخیره‌شده هنگام ورود استفاده می‌کند.
   - اگر سشن متعلق به دامنه دیگری باشد، مسیر ذخیره‌شده نادیده گرفته می‌شود.
   - تزریق کوکی و storage و تمام matcherهای شبکه بدون تغییر مانده‌اند.

3) ui_runner.py
   - رفتار قبلی اجرا و لاگ حفظ شده است.
   - تست‌ها با Python همان .venv که Runner را اجرا کرده است اجرا می‌شوند.
   - اگر یک سناریو 60 ثانیه هیچ خروجی ندهد، همان سناریو متوقف می‌شود،
     timeout داخل لاگ ثبت می‌شود و سناریوی بعدی ادامه پیدا می‌کند.

روش اجرا:
1) ZIP را کامل Extract کنید.
2) install_all_in_venv.bat را اجرا کنید.
3) RUN_RUNNER.bat را اجرا کنید.
4) ابتدا فقط «لاگین و ذخیره سشن» را انتخاب و اجرا کنید.
5) بعد از ساخته‌شدن session.json، تست‌های موردنظر را اجرا کنید.
